# Security

RCBBoard is a personal project, maintained in my spare time. I take security problems seriously, but I cannot promise response times.

## Reporting a security problem

Please **do not** post details of a security problem publicly (not in issues, pull requests or other public places).

GitHub does not have private messages, so:

1. Go to my GitHub profile: https://github.com/Rananjaya
2. Use one of the contact options listed there to tell me that you found a security problem in RCBBoard, and ask for a private way to send the details.
3. Do not include the details in that first message if the channel is public.

When we have a private channel, please send:

- the RCBBoard version or commit,
- what the problem is and what an attacker could do with it,
- how to reproduce it (for example a crafted dictionary file).

## Scope

- In scope: the RCBBoard app and the source code in this repository.
- Not in scope: the original HeliBoard app (please report HeliBoard problems to the HeliBoard project) and third-party components that are not part of this repository, such as user-supplied gesture typing libraries.

Fixes are made on the `develop` branch and included in the next RCBBoard build.
