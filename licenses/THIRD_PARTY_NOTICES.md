### Which data comes from where

This is taken from `scripts/make_emoji_dictionaries.py` and the description of [pull request 53](https://codeberg.org/Helium314/aosp-dictionaries/pulls/53) ("Using tags and ranks from Signal emoji data (first priority), and default and tts from CLDR data").

From Unicode CLDR ([unicode-org/cldr-json](https://github.com/unicode-org/cldr-json)):

- emoji keywords (`default`) and spoken names (`tts`) from `cldr-annotations-full/annotations/<locale>/annotations.json`
- the same fields from `cldr-annotations-derived-full/annotationsDerived/<locale>/annotations.json`
- the full emoji descriptions used for emoji-to-description entries, which come from the CLDR `tts` names

From Signal ([signalapp/emoji-search-index](https://github.com/signalapp/emoji-search-index)):

- emoji search tags from `data/<locale>.json` (`data/en.json` for English, `data/si.json` for Sinhala)
- emoji popularity ranks from `data/en.json`, which the script uses to set suggestion frequencies for every language, including Sinhala

When the same word and emoji pair appears in both sources, the Signal entry is used.

Signal's own README says its index combines two sources: "Annotations from Unicode CLDR project" and "A set of custom tags we've created ourselves." Signal's tag data therefore includes CLDR material too.

## Sinhala word dictionary

RCBBoard bundles a compiled Sinhala spelling dictionary at `assets/dicts/main_si.dict`. It is a word dictionary for the `si` / `si_LK` keyboard. It is separate from `emoji_si.dict`, which is an emoji-name dictionary.

### Source

- Repository: https://github.com/laknath/Sinhala-Dictionary
- Exact commit: `cfcfb500d9e24c4101d9146e2795ec2f0074f385`
- Original file: `sinhala_full_word_list_2010-09-10.txt`
- SHA-256 of that original file: `5e6d95b2e1196cd77639015f3e1155b15adc727b252d0c890cb7d80c198f00bb`

The unchanged original file, the GPL-3.0 licence text, and the upstream copyright notice are in [`third_party/sinhala-dictionary/`](../third_party/sinhala-dictionary/). The editable conversion is `third_party/sinhala-dictionary/main_si.combined`. That `.combined` file is not packaged into the APK. `main_si.dict` is the dictionary compiled from it with `dicttool_aosp.jar makedict`. Every kept word has frequency 0 because the source has no frequency data.

## Sinhala (Wijesekara) keyboard layout

`assets/layouts/main/sinhala_wijesekara.json` was written for RCBBoard and is licensed with the app under GPL-3.0. It contains no code or data copied from other projects. Its key positions follow the Wijesekara keyboard standard (SLS 1134). They were checked against these references, which were only read, not copied:

- Microsoft "Sinhala - Wij 9" (KBDSW09), as listed on kbdlayout.info. © Microsoft Corporation.
- GNU/LKLUG "Sinhala Wijesekera Compatible Keymap" (nongnu.org Sinhala project).
- para-d/si-wijesekara-keyboard (Unlicense).

Sithakuru (GPL-3.0-only) was consulted, but its layout could not be read and nothing from it was used. Mentioning these projects does not mean they endorse RCBBoard.
